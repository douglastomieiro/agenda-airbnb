# agenda-airbnb

Página visual com a agenda de reservas/bloqueios dos anúncios Airbnb
(Studios M1, M2, M3 — São Pedro/SP).

- `index.html` é gerado automaticamente a partir do export oficial de
  calendário (iCal) do Airbnb. Sem preço, sem nome de hóspede — só datas e
  se é reserva ou bloqueio manual.
- Atualizado automaticamente todo dia de manhã por um script agendado no
  PC local (`airbnb-saopedro/publicar_agenda.py`).
- Ver ao vivo: https://douglastomieiro.github.io/agenda-airbnb/
